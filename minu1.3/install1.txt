========================================
        Minu 编辑器 v1.3
========================================

☕ 欢迎使用 Minu 编辑器！

一个轻量级、快速、开源的 Python 代码编辑器
完全使用 Python 标准库开发，无需安装任何第三方包

========================================
✨ 主要特性
========================================

• 完整的 Python 语法高亮
  - 关键字、内置函数、字符串
  - 注释、数字、装饰器
  - 函数、类定义

• 内置代码运行器
  - 一键运行 Python 代码
  - 实时显示输出结果
  - 错误信息高亮显示

• 便捷的编辑功能
  - 行号显示
  - 多主题支持（明亮/暗色）
  - 字体大小调节
  - 快捷键操作

• 文件管理
  - 新建/打开/保存文件
  - 默认保存为 .py 格式
  - 支持中文编码

========================================
⌨️ 快捷键
========================================

F5          - 运行代码
F11/ESC     - 全屏/窗口切换
Ctrl+N      - 新建文件
Ctrl+O      - 打开文件
Ctrl+S      - 保存文件
Ctrl+Z/Y    - 撤销/重做
Ctrl+A      - 全选

========================================
📋 系统要求
========================================

• Windows 7 / 8 / 10 / 11
• Python 3.6 或更高版本（运行代码时需要）
• 无需安装任何第三方包
